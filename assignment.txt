SQL (Structured Query Language) is the standard programming language used to communicate with and manage relational databases.
It allows you to perform tasks such as creating tables, storing new data, updating existing records, and retrieving specific information using "queries." Essentially, it acts as the bridge between a user and a database system (like MySQL, PostgreSQL, or SQL Server).

Types of SQL Commands

DDL (Data Definition Language)
DML (Data Manipulation Language)
DQL (Data Query Language)
DCL (Data Control Language)
TCL (Transaction Control Language)
