ARCHITECTURE:

- Survives tab close, server restart (PM2 keeps it alive)
- One agent instance per user, tracked in a module-level Map keyed by userId
- Agent state persisted in DB — if server restarts, agent resumes if it was running

SETTINGS (all fetched fresh from DB on each scan cycle, never hardcoded):
- Coins list — user selected coins to scan (from agent settings in settings page)
- Timeframe — candle timeframe to scan on (15m | 30m | 1h | 2h | 4h | 1D)
- Scan interval — how often to scan (on candle close of selected timeframe)
- Trading hours — custom PKT hours range (e.g. 9:00–22:00), skip scans outside this window
- Hard filter settings:
  * Min volume (USDT)
  * Min ATR%
  * Trend alignment (optional toggle)
  * RSI zone (optional — e.g. only scan if RSI < 40 or > 60)
  * MACD filter (optional toggle)
- AI provider — GLM-4.7-Flash | Kimi K2 | Claude Sonnet (use user's own API key)
- Min confidence score — default 75, user can change
- Risk per trade % — position size based on account balance
- Max trades per day — hard stop after this many trades
- Daily drawdown limit % — hard stop if DD exceeds this
- Demo/Live mode — skip real Bybit orders in demo mode
- One position at a time — do not scan if a position is already open

SCAN LOOP (runs on every candle close of selected timeframe):
1. Check trading hours — skip if outside PKT window
2. Check guardrails — skip if max trades hit or daily DD exceeded
3. Check open position — skip if position already open (one at a time rule)
4. Fetch latest candles for all selected coins from Binance
5. Run hard filters on each coin — discard coins that fail any filter
6. For each coin that passes hard filters:
   - Build full analysis payload: OHLC candles, RSI, MACD, EMA, volume, ATR, 
     current price, trend direction, support/resistance levels
   - Send to AI with this prompt structure:
     "Analyze this coin for a potential trade. 
      Return JSON only with these fields:
      direction (LONG/SHORT/NONE), 
      confidence_score (0-100), 
      entry_price, 
      stop_loss, 
      take_profit, 
      rr_ratio, 
      reasoning (max 100 chars)"
   - Parse AI response, extract confidence_score
7. Collect all coins with confidence_score >= min threshold (default 75)
8. If multiple coins qualify, pick the ONE with highest confidence score
9. Place trade on that coin:
   - Calculate position size from risk % and account balance
   - Place market order on Bybit (or paper trade in demo mode)
   - Save trade to DB with all details
   - Send Discord alert (if enabled)
   - Set hasOpenPosition = true
10. If no coin scores >= threshold, log "No qualifying coins found" and wait for next candle
