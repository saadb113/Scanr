Fix Pine Script modal not displaying code:

The Pine Script modal opens but shows blank/empty code area.
However the copy button works perfectly — meaning the Pine Script 
is being generated correctly, it just isn't being rendered in the UI.

This is a pure frontend rendering bug. Fix:

1. Check the modal code display element:
   - Find the element where Pine Script code is supposed to render
     (likely a <pre>, <code>, or <textarea> tag)
   - Check if the generated script is being assigned to the correct 
     element's textContent/innerHTML/value property
   - The copy button works so it is reading from somewhere — find 
     exactly what element/variable the copy button reads from and 
     make sure the display element reads from that same source

2. Common causes to check:
   - Modal opens BEFORE the code is generated and injected — 
     fix by generating code first then opening modal
   - Code is being set on an element that doesn't exist yet in DOM 
     when the assignment runs — fix by ensuring modal is rendered 
     before trying to populate it
   - Wrong element ID or class selector being used for display 
     vs what copy button uses
   - Code has special characters (<, >, &) that are being interpreted 
     as HTML and breaking the display — fix by using textContent 
     not innerHTML, or escape the content properly

3. Fix:
   - Make display element use the exact same source as copy button
   - Use textContent to set the code (not innerHTML) to avoid 
     HTML parsing issues
   - Trigger code generation and display population when modal 
     opens, not before
