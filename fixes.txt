Redesign terminal.html to look and feel like Bybit's trading terminal UI.

Design reference — Bybit terminal layout:
- Pure dark theme: #0b0e11 background, #1a1d26 panels, #252936 cards
- Accent colors: Yellow #f0b90b for primary actions, Green #0ecb81 for long/profit, Red #f6465d for short/loss
- Font: Clean monospace/tabular numbers for prices, sans-serif for labels
- Tight dense layout — every pixel used, no wasted space
- Subtle borders: 1px #2b2f3e between panels

Layout (left to right):
1. LEFT PANEL — TradingView chart (takes ~65% width, full height)
   - Symbol input + timeframe selector bar at top of chart
   - TV Chart / Our Chart toggle as tab pills

2. RIGHT PANEL — Order Form (~35% width)
   - Top: Long / Short toggle tabs (green/red, pill style)
   - Account balance row (Available: X USDT)
   - Order type tabs: Market | Limit
   - Input rows (label left, input right):
     - Price (for limit)
     - Quantity (USDT / Coin toggle)
     - Leverage slider with value badge
     - TP input with toggle checkbox
     - SL input with toggle checkbox
   - % quick-fill buttons: 25% 50% 75% 100% (pill buttons)
   - Cost / Max rows below inputs
   - Big LONG or SHORT submit button (green/red, full width, rounded)

3. BOTTOM TABS PANEL (below chart, full width):
   - Tabs: Positions | Open Orders | Assets | Autopilot
   - Table rows: dark alternating rows, monospace numbers
   - Close buttons: small red pill buttons on position rows
   - Autopilot tab: same milestone cards but dark themed

Styling rules:
- All inputs: dark bg #1a1d26, border #2b2f3e, yellow focus ring
- Scrollbars: thin, dark styled
- Hover states on all interactive elements
- Numbers: always monospace, green if positive, red if negative
- Loading skeletons for balance/position data
- Responsive but prioritize desktop (traders use desktop)

Keep all existing JS functionality intact — only change the HTML structure and CSS. Do not break any existing API calls, socket events, or form submission logic.
