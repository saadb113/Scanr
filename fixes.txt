Fix 2 log display bugs:

1. LOGS REVERTING TO TOP ON BOT START:
   - When bot is stopped, new logs correctly append to bottom
   - When bot is started again, logs flip back to showing newest on top
   - This means the log rendering/sorting logic is being re-initialized 
     on bot start and reverting to old behavior
   - Fix: log order (newest at bottom) must be set ONCE globally on 
     page load and never change regardless of bot start/stop state
   - Bot start/stop events must NOT re-render or re-sort the log panel
   - New logs always append to bottom, always, unconditionally

2. DELETED LOGS REAPPEARING ON BOT START:
   - User clicks "Clear All Logs" — logs cleared from UI
   - Bot starts again — deleted logs reappear
   - This means "Clear All Logs" is only clearing the UI/frontend 
     array but NOT deleting from MongoDB
   - Fix: "Clear All Logs" must call DELETE /api/strategy/logs/clear 
     and wipe logs from DB for that strategy
   - On bot start, logs are fetched fresh from DB — if DB is empty, 
     panel stays empty
   - Do not keep any in-memory log cache that survives a clear action
   - After successful DB clear, reset the in-memory log array to [] 
     as well so they cannot reappear
