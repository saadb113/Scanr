Add Free vs Premium tier system to Scanr.
Users register without license key and get free access. Premium unlocks additional pages.

FREE pages (accessible after registration, no payment):

5. PREMIUM PAGE PROTECTION:
Backend middleware — checkPremium:
JavaScript
Copy
const checkPremium = (req, res, next) => {
  if (req.session.user.accountTier === 'premium') {
    return next()
  }
  return res.status(403).json({ 
    error: 'premium_required',
    message: 'This feature requires Premium access'
  })
}
