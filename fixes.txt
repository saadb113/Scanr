After removing the AI agent code, also audit the entire 
Scanr codebase and remove unused files and dead code.
Be conservative — only remove things that are clearly 
unused. Do NOT delete anything if unsure.

1. FIND UNUSED FILES:
   Check these file types for usage:
   - Any .js files in root not imported anywhere
   - Any .html files in public/ not linked anywhere
   - Any .css files not referenced anywhere
   - Any uploaded/temp files in uploads/ folder older than 7 days

   Before deleting any file:
   - Search entire codebase for filename references
   - Only delete if ZERO references found
   - Log every file being deleted: "Deleting unused: filename"

2. FIND DEAD CODE in .js files:
   - Functions defined but never called anywhere
   - Routes defined but never used by frontend
   - Variables declared but never used
   - Commented out code blocks (large chunks)
   - console.log statements left from debugging
   
   Remove only if 100% certain unused.
   Do NOT remove:
   - Any route that might be called from frontend
   - Any function that might be called indirectly
   - Any exported function
   - When in doubt → leave it

3. FIND UNUSED npm PACKAGES:
   Check package.json dependencies:
   - Search each package name in entire codebase
   - If package not imported anywhere → 
     npm uninstall that package
   - Run npm install after cleanup
   - Common candidates: twitter-api-v2, node-cron 
     (from Twitter feature we removed)

4. FIND UNUSED DB MODELS in models.js:
   - Check each Schema/model definition
   - Search if model is imported or used anywhere
   - If completely unused → remove from models.js
   - Keep ALL models that are used anywhere

5. CLEAN UP .env:
   - Remove any env variables no longer used
   - Add comment sections for organization:
     # Server, # Database, # Email, # Bybit, # AI Providers
   - Keep all variables that are still referenced in code

6. SAFETY RULES — never delete:
   - server.js, db.js, models.js, package.json
   - Any file referenced in server.js requires
   - Any HTML page linked in navigation
   - Any file modified in last 7 days
   - public/css/styles.css
   - public/js/app.js
   - .env file

7. AFTER CLEANUP:
   - Start server and verify no errors
   - Visit every page and confirm loads correctly:
     dashboard, scanner, terminal, strategy, 
     setups, challenge, calendar, settings, admin
   - Check browser console for 404 errors
   - Run: npm start and confirm clean startup log
