Support

Frequently Asked Questions

Everything you need to know before getting started.

What exchanges are supported?
Currently Bybit (mainnet and testnet) is fully supported for both spot and linear perpetuals. The platform uses Bybit's V5 API for all market data, order placement, and position management.
Do I need coding knowledge?
No coding knowledge is required. The platform is entirely web-based with a clean dashboard interface. You just need a Bybit account and API keys — the setup guide walks you through everything step by step.
Is this a monthly subscription?
No. Scanr is a one-time payment of $49 for lifetime access. There are no monthly fees, no renewal charges, and all future updates are included at no extra cost.
What is a license key?
After purchasing, you will receive a unique license key. You enter this key once when activating your account. It unlocks full platform access permanently and is tied to your account.
Is my API key safe?
Yes. Your Bybit API keys are stored encrypted per-user in the database and are never exposed in the browser or public endpoints. All Bybit requests are made server-side with proper HMAC authentication.
Can I use this on mobile?
Yes, the platform is fully responsive and works on mobile browsers. However, for the best experience — especially when using the scanner and terminal — a desktop or laptop is recommended.
What if I need help setting up?
We provide a full setup guide at /setup-guide covering everything from Bybit API setup to scanner configuration. You can also reach us directly via Email for personal, one-on-one assistance.
Do I need to know coding to use the strategy builder?
No. The strategy builder is fully visual — drag and drop blocks to build your strategy. No coding knowledge required at all.
Which AI model should I use?
Start with GLM-4.7-Flash — it's completely free and works great for trade analysis. Upgrade to Kimi K2 or Claude Sonnet if you want higher quality analysis.
How do Discord alerts work?
Create a webhook URL in your Discord channel (takes 30 seconds), paste it in Settings → Integrations → Discord. You'll receive formatted alerts for every trade event.
Can the strategy bot trade automatically?
Yes. Build your strategy using blocks, save it, and activate the bot. It monitors your configured coins and places trades on Bybit automatically when your conditions are met.
Is the strategy bot safe to use?
The bot has built-in guardrails: Custom max trades per day, daily drawdown limit, and only 1 position at a time. It cannot exceed these limits.
