✦ Quick Setup

Get Started in Minutes

Follow these 6 steps to set up your account, connect Bybit, and start trading with AI-powered analysis.

1
Purchase & License Key

After payment you will receive a unique license key on your dashboard. Keep it safe.

  • Register at /register
  • You will be redirected to the payment page automatically
  • Send USDT to the wallet address shown
  • Submit your Transaction ID and screenshot as payment proof
  • Wait for verification — Once verified, your payment page updates automatically and you get the license key
  • Click "Activate License", paste the key and you're in
No key yet? Purchase on the Pricing page — $49 lifetime access.
2
Connect Bybit

Connect your Bybit account to start trading.

Go to Settings → Bybit tab
  • Create API key on Bybit: bybit.com → Profile → API Management → Create
  • Enable permissions: Read and Trade
  • Copy your API Key and Secret
  • Paste in Settings → Bybit tab
  • Toggle Testnet OFF for live trading
  • Click Save → Test Connection
3
Choose Your AI Model (Optional)

Three AI models available — pick one for instant trade analysis with entry, SL, TP, and reasoning.

  • GLM-4.7-Flash (Free): Go to open.bigmodel.cn → Sign up free → Get API key → paste in Settings → Integrations → AI Analysis → Select GLM-4.7-Flash → Save
  • Kimi K2: Go to platform.moonshot.ai → Sign up → Create API key → paste in Settings → Integrations → AI Analysis → Select Kimi K2 → Save
  • Claude Sonnet: Go to console.anthropic.com → Sign up (free credits) → Create API key → paste in Settings → Integrations → AI Analysis → Select Claude Sonnet → Save
Tip: Start with GLM-4.7-Flash — it's completely free and works great. Upgrade to Kimi K2 or Claude Sonnet for higher quality.
4
Add Your Coins

Configure which coins the scanner monitors.

  • Go to Settings → Coins tab
  • Add coins you want to scan (e.g. SOLUSDT, LINKUSDT, AVAXUSDT)
  • Click Save
5
Start Scanning

Find your first setup.

  • Go to the Scanner page
  • Cards will load showing all your coins with live signals
  • Look for Bull Div, Bear Div, OB, OS signals
  • Or click Scan Setups for filtered, high-quality opportunities
6
Place Your First Trade

Execute a trade directly from the terminal.

  • Go to the Terminal page
  • Search for a coin using the symbol input
  • Analyze the TradingView chart
  • Click Analyze with AI for a trade suggestion
  • Fill the order form or click Apply from AI
  • Click Place Order
7
Connect Discord Alerts (Optional)

Receive trade notifications directly in Discord.

  • Open Discord → go to any channel
  • Click ⚙️ Edit Channel → Integrations → Webhooks
  • Click New Webhook → Copy Webhook URL
  • In Scanr → Settings → Integrations → Discord
  • Paste webhook URL → Send Test Message
  • Turn on alert toggles you want → Save
Takes 30 seconds: No bot setup, no coding, no approval needed. Just paste your webhook and go.
8
Build Your First Strategy Bot (Optional)

Build a no-code trading bot that monitors coins and places trades automatically on Bybit.

  • Go to Strategy Builder in navigation
  • Click New Strategy
  • Drag filter blocks into the Filters section (Volume Spike, Trading Hours)
  • In the IF block drag entry conditions (RSI Value, Trend 4H)
  • In the THEN section drag Enter Long + SL + TP blocks
  • Click + Add ELSE IF for short conditions
  • Click Save Strategy
  • Click Export Pine Script to backtest on TradingView
  • When ready → select strategy → click Activate Bot
FAQ
Frequently Asked Questions

Everything you need to know before getting started.

What exchanges are supported?

Currently Bybit (Spot and Futures). More exchanges are coming in future updates.

Do I need coding knowledge?

No. The app is fully web-based. Just enter your API keys in settings and you're ready to trade.

Is this a monthly subscription?

No. One time payment of $49 gives you lifetime access to all current and future features.

What is a license key?

After purchase you receive a unique license key. Enter it on first login to activate your account. Each key is tied to a single account.

Is my API key safe?

Yes. Your Bybit API keys are stored encrypted in your account and never shared with anyone. All Bybit requests are signed server-side.

Can I use this on mobile?

Yes. The app is fully responsive and works on all devices including phones and tablets.

What if I need help setting up?

This setup guide covers everything you need. You can also contact us directly on Email for hands-on assistance — we respond fast.

Do I need to know coding to use the strategy builder?

No. The strategy builder is fully visual — drag and drop blocks to build your strategy. No coding knowledge required at all.

Which AI model should I use?

Start with GLM-4.7-Flash — it's completely free and works great for trade analysis. Upgrade to Kimi K2 or Claude Sonnet if you want higher quality analysis.

How do Discord alerts work?

Create a webhook URL in your Discord channel (takes 30 seconds), paste it in Settings → Integrations → Discord. You'll receive formatted alerts for every trade event.

Can the strategy bot trade automatically?

Yes. Build your strategy using blocks, save it, and activate the bot. It monitors your configured coins and places trades on Bybit automatically when your conditions are met.

Is the strategy bot safe to use?

The bot has built-in guardrails: max 3 trades per day, 5% daily drawdown limit, and only 1 position at a time. It cannot exceed these limits.

Need help? Contact us directly.

We're available to help you get set up and answer any questions.
